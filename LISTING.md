# Listing text for skills.aequai.com

## test-me

**One line:** Decide whether a tool really does the job, from evidence of using it, not from its README.

**Short description:**
Before you adopt a new app, library or agent tool, or copy a feature from one, test-me has your AI agent test it the way a careful reviewer would.
- Each promise becomes a single, testable claim.
- The test is fixed before the tool runs.
- The tool is used on synthetic data.
- Every claim gets a plain verdict: keep what you have, run a small pilot, adopt it, or drop it for now.

"Keep what you have" is often the right answer, and the skill says so.

**Who it is for:** anyone choosing tools with an AI agent: founders, operators, developers, and teams that handle sensitive data.

**What you get:** a one-page report with the decision first, the evidence for each claim, and what was not checked.

**Works with:** Claude Code (plugin), and any agent that reads `SKILL.md` folders.
