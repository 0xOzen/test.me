test-me

Decide whether a tool really does the job, from evidence of using it, not from its README.

Before you adopt a new app, library or agent tool, or copy a feature from one, test-me has your AI agent test it the way a careful reviewer would.

  • Each promise becomes a single, testable claim.
  • The test is fixed before the tool runs.
  • The tool is used on synthetic data.
  • Every claim gets a plain verdict:
  • Keep current method
  • Limited pilot
  • Adopt
  • Drop for now

"Keep what you have" is often the right answer, and the skill says so.

Install

In Claude Code:

/plugin marketplace add 0xOzen/test.me
/plugin install test-me@aequai-skills

Any agent that reads SKILL.md folders can use test-me/skills/test-me/ from the repository directly.

What you get

A one-page report with the decision first, the evidence for each claim, and what was not checked.

Who it is for

Anyone choosing tools with an AI agent: founders, operators, developers, and teams that handle sensitive data.
